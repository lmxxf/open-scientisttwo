# Exact Streaming Incremental Byte-Pair Tokenization: Linear-Time Rank-Ordered Two-Interval Compilation & Static Context Certificates

## 1. Formal Problem Definition and Prefix-Consistency Guarantee

Let $\Sigma = \{0, 1, \dots, 255\}$ be the byte alphabet and $\mathcal{R} = ((a_0, b_0), \dots, (a_{R-1}, b_{R-1}))$ be a priority-ordered sequence of merge rules defining a canonical vocabulary $\mathcal{V}$ of size $M = 256 + R$ (Sennrich et al., 2016; Kudo & Richardson, 2018; Zouhar et al., 2023; Berglund & van der Merwe, 2023). Rule $r \in \{0, \dots, R-1\}$ maps $(a_r, b_r) \to t = 256 + r$ with predecessor $p(t) = a_r$, successor $s(t) = b_r$, rank $\operatorname{rank}(t) = r$, and byte length $\ell(t) = \ell(a_r) + \ell(b_r)$.

Given a streaming byte sequence $x_{1:n} \in \Sigma^*$, priority-ranked BPE repeatedly merges the adjacent pair of minimum rank (breaking ties left-to-right), yielding $\theta(x_{1:n}) = (t_1, \dots, t_m)$. An **exact streaming incremental BPE transducer** (Jiang & Gong, `arXiv:2605.30813`; Component-Weighted Centroid Search, `arXiv:2609.40016`) processes one byte $x_n$ per step via `append(x_n)` returning $H[n] = t_m$, while `tokens()` reconstructs $\theta(x_{1:n})$ matching batch BPE at every byte prefix $1 \le k \le n$.

## 2. Formal Differentiation from Jiang & Gong (`2605.30813`) and Component-Weighted Centroid Search (`2609.40016`)

Orienting each merge token $t \ge 256$ to its right operand $s(t)$ forms a successor forest $\mathcal{F}_{\text{suc}}$ rooted at byte atoms. A merge candidate $t$ recognized by the Aho-Corasick automaton (Aho & Corasick, 1975; double-array layout in `arXiv:2207.13870`) is valid at position $n$ iff $k = H[n - \ell(s(t))]$ satisfies the **Prefix Last-Token Condition**:
$$\operatorname{Accept}(t, k) \iff k = p(t) \;\lor\; \exists c \in \operatorname{Child}_{\mathcal{F}_{\text{suc}}}(p(t)) \text{ s.t. } k \in \operatorname{Desc}(c) \land \operatorname{rank}(c) > \operatorname{rank}(t).$$

### How Rank-Ordered Two-Interval Compilation Differs from `arXiv:2605.30813` and `arXiv:2609.40016`
1. **Contrast with Jiang & Gong (`arXiv:2605.30813`)**: Standard DFS intervals $[L_u, R_u)$ test unconstrained ancestry $k \in \operatorname{Desc}(p(t))$ in $O(1)$ time, but under an arbitrary sibling order, checking the strict priority inequality $\operatorname{rank}(c) > \operatorname{rank}(t)$ for the specific child subtree $c \in \operatorname{Child}(p(t))$ containing $k$ requires locating $c$ at runtime via binary search or centroid traversal ($O(\log \Delta)$ or $O(\log^2 L)$ per step).
2. **Contrast and Orthogonality with Component-Weighted Centroid Search (`arXiv:2609.40016`)**: `arXiv:2609.40016` reduces candidate-tree search probes from $O(\log^2 L)$ to $O(\log L)$ by weighting centroid branches by component size, **but** still performs $O(\log \Delta)$ or $O(\log D)$ branch comparisons during tree search.
3. **Our Rank-Ordered Two-Interval Theorem (Theorem 1 — Strict $O(1)$ Predicate in $2R$ Intervals)**: By sorting $\operatorname{Child}_{\mathcal{F}_{\text{suc}}}(a)$ in increasing merge rank order before DFS numbering, all forbidden higher-or-equal priority child subtrees $\{c \in \operatorname{Child}(a) : r(c) \le r(t)\}$ form a **single contiguous DFS prefix** $[L_a + 1, q_t)$, while all admissible child subtrees $\{c \in \operatorname{Child}(a) : r(c) > r(t)\}$ collapse into **one contiguous DFS suffix** $[q_t, R_a)$! Consequently, the complete ancestry-and-priority predicate compiles into at most **two half-open intervals** per rule:
   $$\mathcal{I}_t = [L_{p(t)}, L_{p(t)} + 1) \;\cup\; [q_t, R_{p(t)}),$$
   requiring **strictly $O(1)$ time (at most two scalar interval comparisons, zero binary searches)** and **$2R$ intervals ($4R$ integers) total**. Furthermore, this $O(1)$ predicate is completely orthogonal to candidate-tree search and can be combined with or compared directly against `arXiv:2609.40016`.
4. **Theorem 2 (Strict $O(M+R)$ Single-Pass Update-Before-Read Cutoff Sweep)**: All cutoffs $q_t$ for $t = 256, \dots, 255+R$ are compiled in **strict $O(M+R)$ linear time** without sorting or binary search by initializing `cutoff[u] = L[u] + 1` and, in a single forward sweep $r = 0, \dots, R-1$, updating `cutoff[s(t)] = R[t]` **before** reading $q_t = \text{cutoff}[p(t)]$ (automatically handling self-overlapping rules $p(t) = s(t)$).
5. **Theorem 3 (Sound Static Context Acceptance Certificates $K(C)$)**: For an automaton state with recognized suffix context $C$, if every vocabulary token $w \in \mathcal{V}$ boundary-compatible with the prefix context $C_{1:|C|-\ell(s(t))}$ belongs to $\mathcal{I}_t$, candidate $t$ is statically certified at compile time and bypasses runtime predecessor checks entirely whenever $n > \ell(s(t))$.
